A deadpan toaster error message: the lever is stuck, the bread refuses to come up, and negotiations have failed.

## Run

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
